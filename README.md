# 小丑牌

基于扑克牌型的单机数值小游戏，灵感来自 Balatro。手选 1–5 张组成牌型，限 4 次出牌内累计超过 300 分即胜。

零依赖、纯静态，用一个 HTML 文件完整实现游戏逻辑，目标是让学员通过亲手实现这款游戏体验「AI 全流程开发」的第一课。

## 玩法规则

- 开局发 8 张手牌（标准 52 张牌洗牌）
- 每轮点击选 1–5 张牌，可选择**出牌**（消耗 1 次出牌机会，按牌型计分）或**弃牌**（消耗 1 次弃牌机会，换牌不得分）
- 出牌上限 4 次，弃牌上限 3 次
- 累计得分超过 300 分即胜，出牌耗尽前未达标则败

支持 10 种牌型（同花顺 > 四条 > 葫芦 > 同花 > 顺子 > 三条 > 两对 > 一对 > 高牌），得分公式：`基础分 × 倍率`。

## 安装与运行

无需安装任何依赖，直接用浏览器打开即可：

```bash
# 方式一：直接双击
open index.html

# 方式二：本地 HTTP 服务（推荐，避免字体加载限制）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```
